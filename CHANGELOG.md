# 📝 CHANGELOG - PrivaXion GLOBAL v3.0

## 🎉 Версия 3.0 - Triple Encryption & Security Hardening (2026-06-08)

### ✨ Новые функции

#### 🔐 Тройное шифрование сообщений
- **Слой 1**: XOR шифрование с E2E ключом + Base64
- **Слой 2**: Метаданные с фейковым ключом и хешем настоящего ключа
- **Слой 3**: Финальный Base64 кодинг для скрытия структуры
- **Функции**: 
  - `encryptMessageTriple(text, key)` - шифрование
  - `decryptMessageTriple(encText, key)` - расшифровка с проверкой
  - `generateFakeKey(realKey)` - генерация поддельного ключа
  - `getKeyMetadata(realKey)` - создание метаданных

#### 🛡️ Anti-DevTools Protection
- Блокировка F12 (основные DevTools)
- Блокировка F7 (отладка потока)
- Блокировка F6 (адресная строка)
- Блокировка Ctrl+Shift+I (Windows/Linux DevTools)
- Блокировка Ctrl+Shift+J (консоль)
- Блокировка Cmd+Option+I (Mac DevTools)
- Блокировка Ctrl+S (сохранение)
- Автоматическое обнаружение DevTools по размеру окна
- **Система штрафов**: 4+ попытки → logout + IP блокировка

#### 🚫 IP Blocking System
- `getIPAddress()` - получение IP адреса
- `isIPBlocked(ip)` - проверка IP в черном списке
- `addBlockedIP(ip, reason)` - добавление IP в черный список
- `logDecryptionAttempt(key, success)` - логирование попыток
- **Условие блокировки**: 5 неудачных попыток расшифровки подряд
- **Хранение**: localStorage.px_blocked_ips и localStorage.px_decryption_attempts

#### 🎨 Модальное окно блокировки
- `showSecurityLockdown(ip, reason)` - показ окна при обнаружении взлома
- Красивый дизайн с анимациями
- Информация о заблокированном IP
- Причина блокировки
- Ссылка на техподдержку
- Автоматический logout через 3 секунды

#### ✅ Проверка IP при входе
- При попытке входа проверяется не заблокирован ли текущий IP
- Если IP в черном списке - доступ запрещен
- Показывается модальное окно блокировки

## ⚠️ Известные ограничения

1. **IP может быть динамическим** - при смене сети IP изменится (не повлияет на существующие блокировки)
2. **VPN скрывает истинный IP** - при использовании VPN блокировка неэффективна
3. **Фейковый ключ генерируется случайно** - каждый раз новый при шифровании (это нормально)
4. **localStorage имеет лимит** - максимум ~5-10MB в зависимости от браузера

## 📞 Техническая поддержка

### Если что-то не работает:

1. Очистите кеш браузера (Ctrl+Shift+Delete)
2. Перезагрузитесь (F5)
3. Проверьте консоль (F12... подождите это заблокировано 😄)
4. Прочитайте TESTING_GUIDE.md

### Если IP заблокирован:

1. Используйте другую сеть/VPN (получите новый IP)
2. Очистите localStorage (localStorage.clear())
3. Обратитесь в техподдержку (будет добавлена)
