# 🔐 Функции безопасности PrivaXion GLOBAL

## ⛔ Анти-дебаггинг (Anti-DevTools)

### Заблокированные клавиши:
- **F12** - основные DevTools
- **F7** - отладка потока выполнения
- **F6** - адресная строка/поиск
- **Ctrl+Shift+I** - DevTools (Windows/Linux)
- **Ctrl+Shift+J** - консоль JavaScript
- **Cmd+Option+I** - DevTools (Mac)
- **Ctrl+S** - сохранение страницы

### Система блокировки:
- Первые 3 попытки - предупреждение в toast
- 4-я попытка - выход из аккаунта и добавление IP в черный список
- 5+ попыток - автоматический logout

### Обнаружение открытых DevTools:
- Проверка каждую секунду размера окна браузера
- Если обнаружено (разница > 200px) - немедленный logout

### Блокировка контекстного меню:
- Правый клик запрещен везде кроме сообщений (для реакций)
- Попытка инспектирования вызывает ошибку

## 🔑 Тройное шифрование (Triple Layer Encryption)

### Архитектура:

```
Оригинальный текст
    ↓
[Слой 1] XOR с настоящим E2E ключом + Base64
    ↓
[Слой 2] Добавление метаданных с фейковым ключом
    ↓
[Слой 3] Финальный Base64 кодинг
    ↓
Зашифрованный текст в хранилище
```

### Метаданные (Layer 2):
```json
{
  "realKeyHash": "px_secre..." (первые 10 символов настоящего ключа),
  "fakeKey": "base64EncodedFakeKey",
  "timestamp": 1717858800000,
  "version": 3
}
```

### Процесс дешифрования:
1. **Layer 3**: Удаление финального Base64
2. **Layer 2**: Проверка хеша настоящего ключа
   - Если неправильный хеш → возвращаем `[Сообщение зашифровано неправильным ключом]`
   - Логируем неудачную попытку
3. **Layer 1**: XOR с настоящим ключом (если хеш верный)
4. Возвращаем расшифрованный текст

### Фейковый ключ:
- Генерируется случайно на основе настоящего ключа
- Лежит в открытом виде в метаданных
- При попытке взлома с фейковым ключом - результат будет бессмыслицей
- Позволяет обманить злоумышленника

## 🚫 Система IP блокирования

### Отслеживание попыток расшифровки:
```
decryptionAttempts[ip] = [
  { time: 1717858800000, key: "...", success: true/false },
  { time: 1717858801000, key: "...", success: false },
  ...
]
```

### Условия блокировки:
1. **5 неудачных попыток подряд** → IP добавляется в черный список
2. Заблокированные IP хранятся в `localStorage.px_blocked_ips`
3. При попытке доступа с заблокированного IP:
   - Пользователь выводится из системы
   - Сеанс завершается
   - Отображается сообщение: "⛔ Ваш IP заблокирован навсегда!"

### Хранение:
```javascript
localStorage.px_blocked_ips = ["192.168.1.1", "10.0.0.5", ...]
localStorage.px_decryption_attempts = {
  "192.168.1.1": [...attempts...],
  "10.0.0.5": [...attempts...]
}
```
