# 🧪 Инструкции по тестированию функций безопасности

## 🔧 Как тестировать каждую функцию

### 1️⃣ Anti-DevTools (Анти-F12)

**Что тестировать:**
- [ ] Нажмите **F12** → должно появиться уведомление "DevTools заблокированы! Попытка 1"
- [ ] Нажмите **F12** еще 3 раза → на 4-й попытке будет logout и добавление IP в черный список
- [ ] Попробуйте **Ctrl+Shift+I** → должно заблокироваться
- [ ] Попробуйте **Ctrl+Shift+J** → должно заблокироваться
- [ ] На Mac: **Cmd+Option+I** → должно заблокироваться
- [ ] Попробуйте **Ctrl+S** (сохранение) → должно заблокироваться
- [ ] Откройте DevTools вручную и смотрите что происходит → каждую секунду проверяется размер окна

**Ожидаемые результаты:**
```
Console: ❌ DevTools заблокированы! Попытка 1
Console: ❌ DevTools заблокированы! Попытка 2
Console: ❌ DevTools заблокированы! Попытка 3
Console: ❌ DevTools заблокированы! Попытка 4
→ Logout + Модальное окно блокировки
```

### 2️⃣ Triple Encryption (Тройное шифрование)

**Что тестировать:**

#### В Developer Console:
```javascript
// 1. Получить ключ канала
const key = px_secret_alice_bob; // формируется из имен пользователей

// 2. Зашифровать сообщение
const encrypted = encryptMessageTriple("Hello World", key);
console.log("Зашифровано:", encrypted);

// 3. Расшифровать с правильным ключом
const decrypted = decryptMessageTriple(encrypted, key);
console.log("Расшифровано:", decrypted); // "Hello World"

// 4. Попробовать расшифровать с неправильным ключом
const wrongKey = "wrong_key_12345";
const wrongDecrypt = decryptMessageTriple(encrypted, wrongKey);
console.log("Неправильный ключ:", wrongDecrypt); 
// "🔐 [Сообщение зашифровано неправильным ключом]"
```

**Ожидаемые результаты:**
- Правильный ключ → исходный текст
- Неправильный ключ → сообщение об ошибке
- Метаданные с фейковым ключом видны в консоли при parsing

### 3️⃣ IP Blocking (Блокировка IP)

**Что тестировать:**

#### Тест 1: 5 неудачных попыток
```javascript
// В консоли симулируем 5 неудачных попыток с неправильным ключом
for (let i = 0; i < 5; i++) {
    logDecryptionAttempt('WRONG_KEY', false);
}
// После 5-й попытки IP должен быть заблокирован
```

**Ожидаемый результат:**
```
⛔ IP 123.45.67.89 заблокирован: 5 неудачных попыток расшифровки
Toast: ⛔ IP заблокирован: 5 неудачных попыток расшифровки
```

#### Тест 2: Черный список IP
```javascript
// Проверить черный список
console.log(JSON.parse(localStorage.getItem('px_blocked_ips')));
// ["123.45.67.89", "10.0.0.5", ...]

// Проверить попытки расшифровки
console.log(JSON.parse(localStorage.getItem('px_decryption_attempts')));
// { "123.45.67.89": [{...}, {...}, ...] }
```

#### Тест 3: Попытка входа с заблокированного IP
- Logout
- Добавить свой IP в черный список: 
  ```javascript
  const blockedIPs = JSON.parse(localStorage.getItem('px_blocked_ips'));
  blockedIPs.push('CURRENT_IP');
  localStorage.setItem('px_blocked_ips', JSON.stringify(blockedIPs));
  ```
- Попробовать залогиниться → должно быть отказано
- Должно появиться окно блокировки с сообщением "Ваш IP заблокирован навсегда!"

### 4️⃣ Комплексный тест безопасности

**Сценарий: Попытка взлома сообщений**

1. Создайте чат между двумя пользователями
2. Отправьте сообщение "Важная информация"
3. Откройте DevTools (должно заблокироваться на F12)
4. Попробуйте найти зашифрованное сообщение в localStorage:
   ```javascript
   // В консоли (если она откроется)
   JSON.parse(localStorage.getItem('px_chats_user1')).user2
   // Вы должны увидеть: [{ text: "очень длинная база64 строка с метаданными", ...}]
   ```
5. Попробуйте расшифровать с неправильным ключом 5 раз
6. На 5-й попытке ваш IP должен быть заблокирован

## 🚀 Advanced Testing (Продвинутое тестирование)

### Проверка структуры зашифрованного сообщения:

```javascript
// 1. Отправьте сообщение
const msg = "Тестовое сообщение";
const encrypted = encryptMessageTriple(msg, "test_key");

// 2. Распарьте структуру
const layer3 = atob(encrypted);
const layer2 = JSON.parse(layer3);
console.log("Метаданные:", layer2.meta);
console.log("Настоящий хеш ключа:", layer2.meta.realKeyHash);
console.log("Фейковый ключ (в Base64):", layer2.meta.fakeKey);
console.log("Версия: ", layer2.meta.version); // 3

// 3. Попробуйте использовать фейковый ключ для расшифровки
const fakeKey = atob(layer2.meta.fakeKey);
// Расшифровка с фейковым ключом вернет ошибку или бессмыслицу
```

## ⚠️ Известные ограничения

1. **IP адрес может быть динамическим** - при смене сети IP может измениться
2. **VPN может скрыть истинный IP** - тестирование более сложное
3. **Тройное шифрование требует синхронизации ключей** - обе стороны должны знать настоящий ключ
4. **Фейковый ключ генерируется случайно** - каждый раз новый при шифровании
