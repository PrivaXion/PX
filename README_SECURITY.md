- Автоматическое отслеживание попыток расшифровки
- 5 неудачных попыток → IP заблокирован **НАВСЕГДА**
- Попытка входа с заблокированного IP → сразу logout
- Красивое модальное окно блокировки

## 🧪 Быстрое тестирование

### Тест 1: Anti-DevTools
```
1. Нажмите F12
2. Вы должны увидеть toast: "❌ DevTools заблокированы! Попытка 1"
3. Нажмите F12 еще 3 раза
4. На 4-й попытке -> logout и блокировка IP
```

### Тест 2: Triple Encryption
```javascript
// В консоли (если она откроется через другой способ)
const key = "test_key";
const msg = "Hello World";
const enc = encryptMessageTriple(msg, key);
const dec = decryptMessageTriple(enc, key);
console.log(dec); // "Hello World"

// С неправильным ключом
const dec2 = decryptMessageTriple(enc, "wrong_key");
console.log(dec2); // "🔐 [Сообщение зашифровано неправильным ключом]"
```

### Тест 3: IP Blocking
```
1. Отправьте несколько сообщений
2. Откройте DevTools (попытаться) 5 раз подряд
3. Ваш IP будет заблокирован
4. Попробуйте залогиниться -> откажет доступ
```

## 🔧 Архитектура безопасности

```
Пользователь пишет сообщение
    ↓
[Проверка IP - не в черном списке?]
    ↓
[Слой 1: XOR с E2E ключом]
    ↓
[Слой 2: Добавление метаданных с фейковым ключом]
    ↓
[Слой 3: Base64 кодинг]
    ↓
Хранение в localStorage (зашифровано)
    ↓
При открытии чата:
    ↓
[Слой 3: Decode Base64]
    ↓
[Слой 2: Проверка хеша настоящего ключа]
    ├─ Если неправильно -> "Сообщение зашифровано неправильным ключом"
    ├─ Логирование попытки
    └─ При 5 неудачных -> IP в черный список
    ↓
[Слой 1: XOR с E2E ключом]
    ↓
Исходное сообщение отображается
```
